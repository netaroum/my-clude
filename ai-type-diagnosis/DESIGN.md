# DESIGN.md — 経営者のための「AI活用タイプ診断」キャンペーンサイト

1. 世界観：朝の会議室に光が入るような、明るく前向きな経営の空気。キャンペーンLPの華やかさと、経営者向けの落ち着きを両立。
2. ベース：背景は白 #FFFFFF（固定）。うすい面は #F6F8F7。文字は墨紺 #1C2230、補足は #5D6573。
3. アクセント：ディープティール #0F766E → 朝日のアンバー #F59E0B のグラデーション1本だけ。ボタン・進捗バー・スコアバー・見出しの一語に使う。
4. 区切り：1px のヘアライン #E6EAE8。太線は使わない。
5. フォント：外部ファイルは使わず、端末の日本語ゴシック（ヒラギノ角ゴ／游ゴシック／Noto Sans JP）。見出しは太さ800、字間 0.02em。
6. 文字サイズ：14 / 18 / 22 / 28 / 40 / 56px の6段。本文は18px以上、行間1.8。
7. 余白：8px刻み。セクション上下 112px（スマホ 72px）、カード内 40px（スマホ 24px）。ぜいたくに空ける。
8. 角丸：カード 24px、選択肢 16px、ボタンは丸いピル 999px。
9. 影：やわらかく広い影 0 20px 50px -20px rgba(15,60,55,.18)。ホバー時は少し濃く。
10. レイアウト：中央寄せ 1080px 幅。診断カードは 760px。スマホでは1列。
11. 読み込み時：各セクションが下から 24px、0.7秒でふわっとフェードイン（順番に少しずつ遅らせる）。
12. 質問の切り替え：今の質問が左へスライドアウト、次の質問が右からスライドイン（0.35秒）。戻る時は逆向き。
13. ホバー：ボタンと選択肢は 3px 浮き上がり、影が深くなる。押すと 0.98倍に沈む。
14. 結果：スコアバーは 0 から 1.2秒でスッと伸びる。結果表示の瞬間に軽い紙吹雪（約2.5秒）。
15. CTA：誠実に。ウソの「残りわずか」やカウントダウンは使わない。理由3点＋大きなボタン1つ。
16. 動きを減らす設定の人には、アニメーションと紙吹雪を止める。
