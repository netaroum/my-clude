- 店名：東京かさね菓子店（とうきょう かさねがしてん）
- 場所：東京駅 改札内 1F（架空の区画「赤れんが通り」）

## ファイル
- index.html … ホームページ（表の顔）。管理画面へのリンク1つ
- admin.html … 管理画面（裏側）。ホームページへのリンク1つ
- system-diagram.png … システム全体像の図解（admin.html 内にも同じ図をSVGで掲載）

## 保存データ（localStorage・キーは kasane. で統一）
| キー | 書く側 | 中身 |
|---|---|---|
| kasane.inquiries | HP（追加）／管理画面（更新） | お問い合わせ・取り置き予約の配列 |
| kasane.favorites | HP | お気に入り商品IDの配列 |
| kasane.theme | HP | "light" / "dark" |
| kasane.settings | 管理画面 | しきい値 {autoOk:80, review:50} |
| kasane.auditLog | 管理画面 | 承認・却下などの操作履歴 |
| kasane.seeded | 管理画面 | サンプルデータ投入済みフラグ |

## お問い合わせ1件の形（HPが作る）
{ id:"INQ-20261020-0912-4821", createdAt:ISO文字列, source:"web",
  category:"取り置き予約"|"団体・法人注文"|"商品について"|"取材・コラボ"|"その他",
  name, email, tel, pickupDate:"YYYY-MM-DD"|"" , qty:数値|0, message, status:"new" }
管理画面が追記する項目：score(0-100), tier("auto"|"review"|"reject"), stage, scoreReasons[], history[]

## スコア（100点満点・ルールで計算するモック）と3段階
- 80点以上＝自動OK（テンプレ返信を自動で下書き）／50〜79点＝人が確認／49点以下＝却下（スパム疑い・情報不足）
- しきい値は設定タブで変更可

## 引き継ぎ型ゲート（人が承認してから次へ）
受付 → AI判定 → 【人の承認】 → 対応中（製造リスト・返信送信待ち） → 完了
※ 承認・却下・差し戻しは必ず専用モーダルで確認（ブラウザ標準のconfirmは使わない）

## 管理画面タブ（5つ）
1. ダッシュボード 2. 受信箱（AI判定） 3. 承認ゲート 4. 取り置き・製造ボード 5. 設定・図解
各タブに「この画面でAIに頼むと良いこと」のヒント
